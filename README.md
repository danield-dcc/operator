# devroast

devroast e um app divertido para dar roast em codigo. Cole um trecho, receba uma nota honesta e explore o leaderboard dos piores codigos.

## O que voce pode fazer

- Colar codigo e receber uma nota de roast
- Ativar o modo roast para mais ironia
- Ver a previa do shame leaderboard

## Por que existe

Para deixar code review mais leve, rapido e divertido.

---

Construido com Next.js e um sistema de UI propio.
